# UpUp · 前端 → AI Agent 转型学习计划

> 面向有前端经验、Python 基础薄弱的工程师，用约 **24 周（工作日）** 完成向 **AI Agent 开发工程师** 的系统转型。

## 仓库结构

```text
├── curriculum/          # 学习总纲与阶段详解
│   ├── 00-总纲.md
│   └── phases/          # 六个阶段的详细规划
├── daily/               # 每日推送：学习笔记 + Coding 练习
│   └── YYYY-MM-DD/      # 按日期归档
├── exercises/           # 可运行的练习脚手架与参考实现
├── projects/            # 阶段里程碑项目
└── .automation/         # 自动化推送状态与约定
```

## 怎么用

1. 先读 [`curriculum/00-总纲.md`](./curriculum/00-总纲.md)
2. 每个工作日（周一至周五）上午会自动推送当日学习内容到 `daily/`
3. 按当日 `README.md` 完成阅读与练习，提交你的解答到对应目录（可选）
4. 每阶段结束完成对应 `projects/` 里程碑

## 学习节奏

| 项目 | 说明 |
|------|------|
| 周期 | 约 24 周有效学习（含 2 周缓冲/作品集） |
| 频率 | 周一至周五 |
| 推送时间 | 约上午 10:00 |
| 每日投入 | 建议 60–90 分钟（理论 20–30 + Coding 40–60） |
| 周末 | 可选复盘，不做强制推送 |
